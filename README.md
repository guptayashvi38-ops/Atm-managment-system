**ATM MANAGEMENT SYSTEM**
 An atm management system made by python that allows users to perform the basic banking operations through menu driven interface.

 **FEATURES**
 *The program consists of a menu-driven interface.
 the menu driven interface consists of:
 -Check balance
 -Deposit money
 -Withdraw money
 -Exit
 *Basic input validation

 **CONCEPTS USED**
 -Functions
 -Conditional Statements
 -Loops
 -Variables and data types
